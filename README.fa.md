# proxytun

با یک دستور، **همهٔ** ترافیک لینوکس را از یک پروکسی SOCKS5 یا HTTP عبور بده؛ ترمینال، apt، snap، داکر، برنامه‌های Electron و همه چیز:

```bash
proxytun on 192.168.1.5
```

[English](README.md)

## چرا؟

پروکسی‌ای که در تنظیمات گنوم (Network → Proxy) گذاشته می‌شود فقط روی برنامه‌هایی اثر دارد که خودشان آن را می‌خوانند. ابزارهای خط فرمان، apt، داکر و خیلی از برنامه‌ها آن را نادیده می‌گیرند. متغیرهای محیطی مثل `http_proxy` هم همه چیز را پوشش نمی‌دهند.

proxytun در لایهٔ شبکه کار می‌کند: یک کارت شبکهٔ مجازی (TUN) می‌سازد و کل سیستم را از آن عبور می‌دهد، پس هیچ برنامه‌ای نمی‌تواند پروکسی را دور بزند. این ابزار برای حالتی ساخته شده که گوشی اینترنتش را به‌شکل پروکسی به اشتراک می‌گذارد (مثلاً با Every Proxy) و لپ‌تاپ باید کامل از آن استفاده کند، ولی با هر پروکسی SOCKS5 یا HTTP کار می‌کند.

## امکانات

- **کل سیستم:** با TUN و [sing-box](https://github.com/SagerNet/sing-box).
- **بدون نشت DNS:** DNS از طریق TCP و از داخل خود پروکسی گرفته می‌شود، پس جواب آلوده نمی‌گیری.
- **تشخیص خودکار UDP:** اگر پروکسی UDP را پشتیبانی کند عبور داده می‌شود؛ وگرنه فوراً رد می‌شود تا برنامه‌ها سریع سراغ TCP بروند.
- **بررسی سلامت:** اگر پروکسی قطع شد (گوشی جدا شد یا IP عوض شد)، اینترنت مستقیم می‌شود و با برگشتن پروکسی خودکار وصل می‌شود. با `--kill-switch` به‌جای آن ترافیک بسته می‌شود.
- **پروفایل:** مثل `proxytun on phone` و `proxytun on office`.
- **دکمه در Quick Settings گنوم:** روشن و خاموش کردن و عوض کردن پروفایل از پنل، بدون پرسیدن رمز.
- **بعد از ریستارت:** آخرین پروفایل خودکار روشن می‌شود، تا وقتی `proxytun off` بزنی.
- **نصب و حذف تمیز.**

## نصب

```bash
git clone https://github.com/alizn7/proxytun
cd proxytun
sudo ./install.sh
```

اگر دانلودها روی شبکه‌ات بسته است، نصب را از خود پروکسی انجام بده:

```bash
sudo ./install.sh --proxy socks5h://192.168.1.5:1080
```

بعد یک بار خارج شو و دوباره وارد شو. در گنوم دکمه را این‌طور فعال کن:

```bash
gnome-extensions enable proxytun@alizn7.github.io
```

## استفاده

| کار | دستور |
|---|---|
| روشن کردن با آدرس جدید (SOCKS5، پورت 1080) | `proxytun on 192.168.1.5` |
| پورت دیگر | `proxytun on 192.168.1.5:1090` |
| پروکسی HTTP | `proxytun on 192.168.1.5:8080 -t http` |
| با نام کاربری و رمز | `proxytun on 192.168.1.5 -u USER -p PASS` |
| ذخیره با اسم و استفادهٔ بعدی | `proxytun on 192.168.1.5 -n phone` و بعد `proxytun on phone` |
| روشن کردن آخرین پروفایل | `proxytun on` |
| بستن ترافیک وقتی پروکسی قطع است | `proxytun on phone --kill-switch` |
| خاموش کردن (و روشن نشدن بعد از ریستارت) | `proxytun off` |
| وضعیت و IP خروجی | `proxytun status` |
| پروفایل‌ها | `proxytun list` و `proxytun add` و `proxytun rm` |
| تست پروکسی بدون تغییر چیزی | `proxytun test 192.168.1.5` |
| لاگ‌ها | `proxytun logs -f` |

هر وقت IP گوشی عوض شد فقط بزن `proxytun on IP_جدید`؛ پورت و بقیهٔ تنظیمات پروفایل حفظ می‌شود. اگر IP اشتباه باشد، proxytun چیزی را عوض نمی‌کند تا اینترنتت قطع نشود.

## محدودیت‌ها

- آدرس پروکسی باید IPv4 باشد.
- وقتی روشن است IPv6 بسته می‌شود تا نشت نداشته باشد.
- `ping` از پروکسی رد نمی‌شود؛ برای تست از `proxytun status` استفاده کن.
- UDP فقط وقتی کار می‌کند که پروکسی پشتیبانی کند (خیلی از اپ‌های گوشی نمی‌کنند).

## حذف

```bash
sudo ./uninstall.sh            # پروفایل‌ها می‌مانند
sudo ./uninstall.sh --purge    # همه چیز پاک می‌شود
```
